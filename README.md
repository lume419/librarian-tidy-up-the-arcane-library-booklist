# Librarian: Tidy Up the Arcane Library — Booklist

Registre interactif (page HTML autonome) pour suivre la progression de rangement de la bibliothèque arcanique : étagères par rayon (rez-de-chaussée / étage), séries à cocher, recherche, filtres par étage, et sauvegarde de la progression dans le navigateur (localStorage).

## Utilisation

- **En ligne** : accédez directement au site sur GitHub Pages → https://lume419.github.io/librarian-tidy-up-the-arcane-library-booklist/
- **En local** : téléchargez ce dépôt et ouvrez simplement [`index.html`](./index.html) dans un navigateur — aucune installation ni backend requis.

## Fonctionnalités

- Recherche par série, étagère ou rayon
- Filtrage par étage (rez-de-chaussée / étage)
- Masquage des séries terminées
- Progression sauvegardée localement (par navigateur)
- Réinitialisation de la progression
